# Sitio web en español · Vector Design Group

Sitio estático (HTML, CSS y JavaScript sin dependencias) para servicios de IA y desarrollo digital dirigidos a empresas de Caracas.

- Nombre de marca: constante `BRAND` al final de `index.html` (y las etiquetas `<title>`/Open Graph del `<head>`).
- Publicado con GitHub Pages desde la rama `main` (raíz).
